## Available now

- Arbitrary account profiles with independent tsnet identities.
- Host discovery across accounts.
- OpenSSH transport and per-host configuration.
- Herdr attachment, session listing, and a combined local view with `herdr open`.
- Native `orca serve` runtime pairing and SSH-tunnel reconnection.
- tmux or Zellij terminals with a searchable box picker and saved backend preference.
- TCP port forwarding, ranges, named HTTP routing and localhost redirect rewriting.
- macOS and Linux builds, with release and installer tooling.

## Planned: process picker

Discover listening ports and the processes that own them, then choose what to forward. Start with SSH and existing host tools; add a host helper if continuous updates justify it.

## Planned: task dispatch

Create isolated checkouts and launch agents on a selected host. A cross-host handoff should transfer code and context explicitly; it should not pretend to migrate a live process.

There are no committed delivery dates. Current command behavior is documented in the [CLI reference](/docs/commands).
